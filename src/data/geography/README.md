# Syrian geography data

- Dataset: OpenSyria Data Geography
- Release: v0.1.5
- Source: https://github.com/Open-Syria/data-geography/tree/v0.1.5
- Dataset page: https://opensyria.org/datasets/geography
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License text: https://creativecommons.org/licenses/by/4.0/

This compact JSON asset contains the release's 14 governorates, 62 districts, 272 subdistricts, and 7,605 locality records. It retains the stable OpenSyria IDs, Arabic/English names, hierarchy references, locality kind, and source centroid coordinates required by Matjar's location selector.

Attribution to OpenSyria and the release's underlying source datasets must be preserved. Do not silently replace the pinned dataset with unreviewed live data. To upgrade, review the new tagged release, its data quality notes and license, regenerate the compact asset, update the version marker and tests, and document the change.
